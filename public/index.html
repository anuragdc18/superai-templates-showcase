Questions

Good to know.

The live demos run without a server, so forms open WhatsApp and the admin panel is hidden. The full version has both.

Are the demos the real websites?

Yes — the same design, pages and chatbot. The demos run on free static hosting, so the admin panel is switched off and forms open WhatsApp instead of saving the lead.

Do I need to pay for an AI or chatbot service?

No. The chatbot is rule-based and runs in the visitor's browser. You teach it new answers from the admin panel.

Can I change colours and the logo?

Yes. Each template starts with its own palette, and you can change the logo, colours and contact details from Admin → Logo & Colours.

Where do the leads go?

Into your admin panel, stored in your own MySQL database on Hostinger (or a local file when running on your computer).

Can I switch to a different design later?

Yes. All 12 templates share the same backend and services, so moving from one design to another keeps the same features.
