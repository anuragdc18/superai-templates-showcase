# SuperAI Templates — showcase

One page that presents all 12 business website templates with live previews and links to each demo.
Plain HTML/CSS/JS in `public/` — no build step.

- Edit names, descriptions, colours or the GitHub account in `public/data.js`.
- Optional: put your WhatsApp number in `CONTACT_WHATSAPP` (in `public/data.js`) to show "Ask on WhatsApp".
- Screenshots live in `public/shots/` (`<id>-desktop.webp`, `<id>-full.webp`, `<id>-phone.webp`).
- Preview locally: open `public/index.html` in a browser.
- Every push to `main` publishes it to GitHub Pages (`.github/workflows/github-pages.yml`).
